# 🎓 YAML Masterclass Quiz (24 Questions & Complete Answer Key)

1. **What does YAML stand for?**
   - Answer: YAML Ain't Markup Language (recursive acronym).
2. **Standard YAML file extensions?**
   - Answer: `.yaml` or `.yml`
3. **Symbol separating keys from values?**
   - Answer: Colon followed by a space (`: `).
4. **How are comments written?**
   - Answer: `# comment`
5. **Indentation rule in YAML?**
   - Answer: Spaces only (Tabs strictly forbidden).
6. **Valid string scalar syntax?**
   - Answer: `name: Dilshad`
7. **Representation of block list?**
   - Answer: Hyphens (`- item`) at the same indentation level.
8. **Inline sequence syntax?**
   - Answer: `[item1, item2, item3]`
9. **Boolean true in YAML 1.2?**
   - Answer: `true`
10. **Numeric integer representation?**
    - Answer: `age: 25`
11. **What does null (or ~) represent?**
    - Answer: Absence of a value.
12. **Nested mapping syntax?**
    - Answer: 2 spaces of indentation below the parent key.
13. **Python equivalent of YAML mapping?**
    - Answer: Dictionary (`dict`).
14. **Python equivalent of YAML sequence?**
    - Answer: List (`list`).
15. **Purpose of quotes in YAML?**
    - Answer: Preserving literal strings, escape sequences, and special characters.
16. **Literal block scalar syntax (preserves line breaks)?**
    - Answer: Pipe symbol (`|`).
17. **Folded block scalar syntax (folds newlines into spaces)?**
    - Answer: Greater-than symbol (`>`).
18. **Purpose of YAML anchor (&) and alias (*)?**
    - Answer: Reusing configuration blocks across documents without duplication.
19. **Symbol defining an anchor?**
    - Answer: `&`
20. **Symbol referencing an alias?**
    - Answer: `*`
21. **Marks the start of a YAML document?**
    - Answer: `---` (three hyphens)
22. **Standard Python YAML library?**
    - Answer: `PyYAML`
23. **Safe loading function in PyYAML?**
    - Answer: `yaml.safe_load()`
24. **Most common DevOps use cases?**
    - Answer: Docker Compose, GitHub Actions, Kubernetes manifests, Helm charts.
